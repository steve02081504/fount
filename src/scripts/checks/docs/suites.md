# Static Check Suites

Full rule set per suite of `fount test checks`. Overview: [AGENTS.md](../AGENTS.md).

| Suite | Enforces |
| --- | --- |
| `html_meta` | HTML meta / landmarks / `drawer-toggle` / aside ARIA; `og_meta_list` `under` prefix filter; pages readme/EULA redirect locales vs `docs/readme/` / `docs/EULA/` |
| `meta_language` | Full HTML `og:title` / `og:description` / `name="description"` carry no Han / kana / Cyrillic; `<title>` is empty (i18n-supplied) or Chinese-free; an empty title's `<pageid>.description` in en-UK must equal the page's `description` and `og:description` |
| `info` | parts `locales.json` / `achievements_registry.json` info + remote icon URL; no `null` leaf under a part `locales.json` (a failed `update-locales.py` run leaves `null` for the next retry — committing it ships an empty name / description) |
| `home_registry` | `home_registry.json` `info` keys resolve in every authoritative locale (`AUTHORITATIVE_LOCALES`: zh-CN, en-UK, ja-JP); display entries (`home_function_buttons` incl. `sub_items`, `home_interfaces`) carry a non-empty `title` |
| `i18n_keys` | locale key structure + shared-path value kinds vs zh-CN + shared-path `${placeholder}` sets vs zh-CN + **key-set coverage vs zh-CN** (no locale misses or invents a leaf / node) + emoji.json must not carry Han/kana/Cyrillic + emoji.json must not repeat a zh-CN leaf verbatim |
| `i18n_copy` | locale **copy** carries no machine-translation residue: no `null` / unjustified empty leaf, product name never mangled to `font` / `fonte://` / a per-language alias (`fontein`, `lettertype` in nl-NL) (en-UK / fr-FR exempt, font-family-style tokens exempt), no space inside a hyphenated compound (CLI flags, spaced dashes and elided conjunctions exempt), the source's leading/trailing newline and side-whitespace frame is preserved, no zero-width space / word joiner / BOM / soft hyphen (ZWJ and ZWNJ stay legal), no doubled space between words the source does not have, no letters from a writing system the locale does not use (Cyrillic inside Hindi, Han inside Russian; `emoji` is exempt, it speaks in symbols), every literal token the source carries survives (`fount <subcommand>`, `--flag`, a backticked token, a file path, a dot-file, an `ENV=value`, an `id_1234567890` example, a `scheme://`; a token the en-UK reference also dropped counts as a deliberate rewrite, and a keyboard shortcut may be capitalised), every camel-case identifier the source carries survives verbatim (`entityHash`, `streamingSfuWss`, `wantIds`; `emoji` is exempt), no English function word left inside a translated value where the source is Chinese (`the`, `and`, `please`, `when`, `this`, `from` … — words no other language borrows; the ones that collide with real German/Dutch/Icelandic/Portuguese words are excluded, borrowed idioms like `drag-and-drop` are exempt), and no space before a comma / ellipsis / sentence-final period (ko-KR: never before a colon), no `en-UK` leaf that answers a source leaf with nothing but an emoji (an emoji is a glyph of the page — render it in the markup and write this locale real text), and no `lzh` leaf without Han where the `zh-CN` source carries Han (`fountConsole.server.standingBy` is exempt: the Kamen Rider 555 line documented in `src/public/locales/decl.md`). Scanner: `src/scripts/checks/i18n_copy.mjs` |
| `i18n_refs` | `data-i18n` / `setElementI18n` objects need a DOM applicator; string APIs + `path/fount.{ps1,sh}` keys must resolve to strings; a string-API call's inline params must cover the key's `${placeholder}`s (`handleError` auto-provides `error`; non-literal args are skipped) |
| `reshape_i18n_keys` | `.esh/commands/reshape_i18n_keys.py --self-test` |
| `update_locales` | `.esh/commands/update-locales.py --self-test` (string↔single-applicator + string↔switch) |
| `update_locale_data` | `.esh/commands/update_locale_data.py --self-test` (core `set`/`move`/`order` operations + `--help`/`-h` invalid-argument regression) |
| `locale_copy_sample` | `.esh/commands/locale_copy_sample.py --self-test` (deterministic sampling + validated patch application; the loop is documented in [locale-edits.md](../../../public/locales/docs/locale-edits.md)) |
| `locale_copy_worklists` | `.esh/commands/locale_copy_worklists.py --self-test` (per-locale `brand.md` / `markup.md` / `drift.md` review worklists: a product name translated into a local word, dropped markup, and one source sentence rendered several ways inside a locale) |
| `agents_md_english` | `AGENTS.md` + linked `.md` English-only; non-`AGENTS.md` under `docs/` |
| `text_lf` | UTF-8 text (fatal decode, no NUL; empty files exempt) must be LF; text ends with exactly one LF (0 or multiple fail; single-line `.svg` must instead end with no LF); no leading LF (leading UTF-8 BOM skipped); under `fount test` scopes to triggered files when set. **Auto-fix**: running this suite first rewrites violating files via `fixTextLf` (normalize line endings, fix leading/trailing LF, preserve BOM), then re-scans to verify |
| `jsdoc_no_english` | JSDoc: summaries Chinese (CJK required; pure English flagged); multi-line blocks must put a line break right after the opening `/**` and before the closing `*/` (no content on either marker line); a multi-line block must own its source line (no `createClient({ /**` badge style), its enclosing literal must already be expanded (`const client = create({` then each member on its own line — never `create({ a: 1, /**` or `*/` sharing a line with a member). Single-line blocks and inline `/** @type … */` casts are exempt |
| `locale_md_align` | Parallel `Stem.locale.md` families (`docs/EULA`, `docs/readme`): same line count; per-line heading / hr / quote / fence / list marker / bold / italic / link / image / inline-code counts vs `en-UK`. Same suite: EULA / README / `list.csv` / `locales/*.json` locale **ids** must be one set |
| `theme_radius` | Themed frontend (`src/public/**` + `.github/pages/**`, excl. `test/`) must not hardcode theme-controlled styling: Tailwind fixed-radius classes (`rounded`, `rounded-sm/md/lg/xl/2xl/3xl`, corner variants, **`rounded-full`** avatar circles, **daisyUI `btn-circle`** circular buttons), CSS `border-radius: <length>`, custom `--radius-*: <length>` var definitions (bypass theme — use `var(--radius-box)` etc.), or hardcoded border width `border: <px>` / `border-width: <px>` (bypass `--border`) — use theme-aware `rounded-selector` / `rounded-field` / `rounded-box` / `rounded-btn` / `rounded-badge`. Avatar circle and circular buttons must follow theme (square under cyberpunk) — use `btn-square` (equal-size, radius follows theme; not a hard square despite the name, see [saadeghi/daisyui#4687](https://github.com/saadeghi/daisyui/issues/4687)). Deliberately-thick decorative borders (avatar rings, status dots, emphasis bars) may keep px width with an above-line `/* theme-radius-ignore */` (skips only the next line) |
| `theme_color` | Themed frontend (same scope as `theme_radius`) must not use `var(<custom prop>, <hardcoded color>)` fallbacks on non-theme vars (`--bg-panel, #1e1e1e` etc. — page-local/undefined vars fall back to dark-theme colors, breaking light themes like the emoji-pack-preview card). Fallbacks must be theme vars (`var(--text-muted, var(--color-base-content))`) or dropped. Theme vars (`--color-*` / `--radius-*` / `--rounded-*` / `--border`) with literal fallbacks are safe. `*.user.js` (theme-less userscripts) excluded; an above-line `/* theme-color-ignore */` skips the next line |
| `icon_crossorigin` | Themed frontend (same scope as `theme_radius`) icons must be requested in CORS mode so the `<img>` download, `svgInliner`'s cors fetch and the prefetcher share one cache entry — without `crossorigin="anonymous"` the `<img>` is a no-cors (opaque) response and every icon is downloaded twice. Covers `<img src="https://api.iconify.design/…">` (incl. JSON-escaped) and `target.src = …` (icon-CDN literal, or a constant holding one; the file must set `target.crossOrigin` earlier). Only known-CORS icon hosts are checked — the attribute would break an arbitrary user-data avatar domain. Above-line `/* icon-crossorigin-ignore */` skips the next line; **auto-fix** adds the attribute / inserts `target.crossOrigin = 'anonymous'` before a bare `src` assignment (a guarded `if (x) x.src = …` line is reported but left for a human). Data-driven image URLs (part avatars, achievement icons, plugin registry HTML) compute the attribute at render time with `pages/scripts/lib/corsImage.mjs` (`corsImgAttribute`, `corsifyHtml`, template scope) |
| `daisyui_var` | Themed frontend (same scope as `theme_radius`) must use daisyUI semantic color vars in full spelling (`--color-base-100` / `--color-base-content` / `--color-primary` / `--color-warning` …), never the v4 abbreviations (`--b1` / `--b2` / `--b3` / `--bc` / `--p` / `--wa` …) — v5 keeps them as compat aliases only and components read `--color-*`, so hand-written abbreviations silently break. Comments are exempt; an above-line `/* daisyui-var-ignore */` skips the next line |
| `no_manual_svg` | Themed frontend (same scope as `theme_radius`) must not hand-write inline `<svg>` graphics in HTML / JS / TS / CSS strings — icons come from the Iconify CDN and are inlined by `svgInliner` (theme-coloured). Only a complete element (`<svg …>` followed by a shape child `<path>` / `<rect>` / `<g>`…) is flagged; string fragments (`replace('<svg', …)`, `/<svg\b/`) and interpolation wrappers (`<svg id="${id}">${html}</svg>`) are not. Comments are exempt; an above-line `/* no-manual-svg-ignore */` skips the next line |
| `motion_hygiene` | Themed frontend (same scope as `theme_radius`) must not write motion that janks the compositor: no `transition: all` (incl. Tailwind `transition-all`, `transition-property: all`, and implicit-all `transition: 0.2s ease`), no transitions on reflow properties (`width` / `height` / `min|max-*` / `inset*` / `margin*` / `padding*` / `flex-basis` / `grid-template-*`) — animate `transform` / `opacity` or `grid-template-rows` instead; `will-change` only on compositor-friendly props (`transform` / `opacity` / `filter` / `backdrop-filter` / `scroll-position` / `contents`). Above-line `/* motion-ignore */` (CSS) or `<!-- motion-ignore -->` (HTML) skips the next line for intentional layout animation (progress bars, card resize, height reveal). Scanner: `src/scripts/checks/motion_hygiene.mjs`. Rationale + judgment rules: [motion-notes.md](../../../public/pages/docs/motion-notes.md) |
| `ms_literal` | Deno-runtime source (`src/scripts/**`, `src/server/**`, `path/**`, part `src/` + server-side `shared/`) must not hand-compute millisecond products (`N * 60 * 1000`, `N * 24 * 60 * 60 * 1000`, `N * 3600 * 1000`, …) — use `ms('…')` from `src/scripts/ms.mjs`. Browser-served code (`src/public/pages/`, part `public/`, `.github/pages/`) can't import the helper, so it's excluded; `*.test.mjs` / `*.spec.mjs` and the helper itself are excluded too |
| `build_string` | Source (`**/*.{mjs,js,ts}`; `*.test.mjs` / `*.spec.mjs` excluded) must build static multi-line text with a multi-line template literal instead of `[...].join('\n')` (no top-level spread elements) or a `+` chain made purely of string/template literals containing a newline. A single-use `const` string returned as the sole `${…}` interpolation of a template must inline the expression. Scanner: `src/scripts/checks/build_string.mjs` |
| `no_ts_import` | fount uses `.ts` **only for JSDoc type declarations** — actual logic lives in `.mjs` / `.js`. So `.mjs` / `.js` must not runtime-import a repo-local `.ts` file (`from` / side-effect `import` / re-export / dynamic `import()`); runtime values (constants, predicates, factories) belong in a `.mjs` / `.js` module. JSDoc `{import('./x.ts')}`, comment, and string text are excluded, as are remote / package-manager specifiers (`https:` / `npm:` / `jsr:` / `node:`). Scanner: `src/scripts/checks/no_ts_import.mjs` |
